## 1. ระบบนี้คืออะไร

ONEBOOK คือระบบบัญชีสำหรับกลุ่มบริษัท ทำเอกสารขาย-ซื้อ รับ-จ่ายเงิน ลงบัญชีอัตโนมัติเข้าสมุดรายวัน/แยกประเภท ออกงบการเงินและรายงานภาษี บริหารสินค้าคงคลัง ทรัพย์สินถาวร และปิดงวด ONEBOOK เป็น "สมุดบัญชีหลัก (book of record)" และเจ้าของผังบัญชี เชื่อมกับ ONE Asset (ทรัพย์สิน) และ One OA (ขออนุมัติ) ผ่านปุ่มสลับระบบและ API

## 2. เข้าใช้งาน บทบาท และหลายบริษัท

เข้าสู่ระบบที่ `/login` (อีเมล+รหัสผ่าน) หรือ SSO (OIDC/GoodHR) · สลับบริษัทที่มุมบน (CompanySwitcher) · ปุ่มสลับระบบไป "ทรัพย์สินถาวร (ONE Asset)" และ "ขออนุมัติ (OA)"

### บทบาท (seed เริ่มต้น)
| บทบาท | ขอบเขตโดยย่อ |
|---|---|
| **owner** เจ้าของกิจการ | ทุกสิทธิ์ (`*`) |
| **accounting_manager** สมุห์บัญชี | สร้าง/แก้/อนุมัติเอกสาร ผ่านรายการ/กลับรายการ ปลดล็อกงวด |
| **accountant** พนักงานบัญชี | สร้าง/แก้ แต่ไม่อนุมัติ/ผ่านรายการ/ปิดงวด |
| **sales** ฝ่ายขาย | เอกสาร+ผู้ติดต่อ ดูสินค้า (ซ่อนราคาทุน/ต้นทุน) |
| **purchasing** ฝ่ายจัดซื้อ | งานฝั่งซื้อ |
| **executive** ผู้บริหาร | ดู/ส่งออกได้ทั้งหมด |
| **auditor** ผู้ตรวจสอบ | ดู + ดู audit |

สิทธิ์เป็นคู่ (ทรัพยากร, การกระทำ) การกระทำมี: ดู/สร้าง/แก้/ลบ/อนุมัติ/ผ่านรายการ/กลับรายการ/ส่งออก/ปลดล็อก/ข้ามเงื่อนไข · ควบคุมการมองเห็นด้วย RLS ตามบริษัทที่สังกัด และมีการบังมาส์กคอลัมน์/กรองแถวได้

### บริษัทในกลุ่ม (seed)
TOPONE (ท็อป วัน ดิสทริบิวชั่น), RABBIT (แรบบิท ประเทศไทย), SHD (เอสเอชดี เทคโนโลยี), PTC (พี ที ซี), HASHTAG (แฮชแท็ก ซีเล็คชั่น), TERRA (เทราโนวา เทคโนโลยี) · สร้างบริษัทใหม่ด้วยสิทธิ์ group-admin (ระบบจะ seed ผังบัญชี/บทบาท/เลขเอกสาร/ช่องทางเงินสดให้)

## 3. ภาพรวมเมนู

**ภาพรวม**: แดชบอร์ด (`/dashboard`), ภาพรวมกลุ่มบริษัท (`/group`), ตารางงาน (`/tasks`), คิวอนุมัติ (`/approvals`), การแจ้งเตือน (`/notifications`), คลังเอกสาร (`/documents/library`)

**รายรับ (ขาย)** `/sales/...`: ใบเสนอราคา, ใบสั่งขาย, ใบส่งของ, ใบวางบิล, ใบแจ้งหนี้, ใบกำกับภาษี, ใบเสร็จรับเงิน, ใบลดหนี้, ใบเพิ่มหนี้, ใบรับเงินมัดจำ

**รายจ่าย (ซื้อ)** `/purchase/...`: ใบขอซื้อ, ใบสั่งซื้อ, ใบรับสินค้า, **ซื้อสินค้า/บริการ (bill)**, **บันทึกค่าใช้จ่าย (expense)**, รับใบลดหนี้, ใบจ่ายเงินมัดจำ + นำเข้าด้วย AI (`/documents/ai-import`, OCR+AI)

**ผู้ติดต่อ / สินค้า**: ผู้ติดต่อ (`/contacts`) + ลูกค้าประจำ/รอบขาย, สินค้า/บริการ (`/products`) + กลุ่มสินค้า, สินค้าคงคลัง (`/inventory`) + คลัง/ล็อต/ตรวจนับ/ต้นทุนนำเข้า/การจอง

**การเงิน** `/finance`: ช่องทางการเงิน, รับ-จ่ายเงิน, เช็ค, กระทบยอดธนาคาร

**บัญชี** `/accounting`: ผังบัญชี (coa), สมุดรายวัน (journal), บัญชีแยกประเภท (ledger), รายการซ้ำ/ตัดจ่าย (recurring), งบประมาณ, ตรวจก่อนปิดงบ (close-check), ปิดบัญชีสิ้นปี (year-end)
> หน้าทรัพย์สินถาวรใน ONEBOOK ถูกซ่อนจากเมนู เพราะย้ายไปใช้แอป ONE Asset แยก (เข้าผ่านปุ่มสลับระบบ)

**รายงาน** `/reports`: KPI ผู้บริหาร, งบทดลอง, เทียบสองงวด, งบกำไรขาดทุน, งบแสดงฐานะการเงิน, งบกระแสเงินสด, อายุลูกหนี้/เจ้าหนี้, วิเคราะห์ขาย-ซื้อ, กำไรขาดทุนแยกแผนก, วงเงินเครดิต, ตามพนักงานขาย, ของค้างส่ง, อัตราแลกเปลี่ยน

**ภาษี** `/tax`: ภาษีขาย/ซื้อ, ภ.พ.30, หัก ณ ที่จ่าย (WHT), ภาษีซื้อยังไม่ใช้สิทธิ์, e-Tax Invoice

**ตั้งค่า** `/settings`: โปรไฟล์, บริษัทในเครือ, ผู้ใช้งาน, สายอนุมัติ, บทบาทและสิทธิ์, รูปแบบเลขที่เอกสาร, แผนก/มิติ, พนักงานขาย, นำเข้าข้อมูล, ปิดงวด (Freeze), ความปลอดภัย, ช่องทางขายออนไลน์, ประวัติการใช้งาน (audit)

## 4. วงจรเอกสารและการลงบัญชี

### สถานะเอกสาร (doc_status)
ฉบับร่าง (draft), รออนุมัติ (awaiting_approval), อนุมัติแล้ว/ผ่านรายการ (approved), จ่าย/รับบางส่วน (partial), ชำระครบ (paid), เกินกำหนด (overdue), ยกเลิก (void), ปิด (closed)

### ขั้นตอนทั่วไป
1. **สร้างเอกสาร** (`บันทึก`) — ระบบออกเลขเอกสารอัตโนมัติ (ตามตั้งค่าที่ `/settings/numbering`), คำนวณ VAT/หัก ณ ที่จ่ายให้, บันทึกเป็น **ฉบับร่าง** · ห้ามบันทึกวันที่ที่อยู่ในงวดที่ปิดแล้ว
2. **อนุมัติ/ผ่านรายการ** (`อนุมัติ`) — เรียก `post_document` ลงบัญชีเข้าสมุดรายวันอัตโนมัติ แล้วสถานะเป็น **approved**
3. **รับ/จ่ายเงิน** — บันทึกการรับชำระ/จ่ายชำระ → สถานะเป็น partial/paid
4. **ยกเลิก (void)** — สร้างรายการกลับบัญชี (ไม่ลบของเดิม เก็บร่องรอย) ต้องมีเหตุผล
5. **แปลงเอกสารต่อเนื่อง** — เช่น ใบเสนอราคา→ใบแจ้งหนี้→ใบกำกับภาษี→ใบเสร็จ (คัดลอกผู้ติดต่อ+รายการ อ้างอิงเอกสารต้นทาง)

### การลงบัญชีอัตโนมัติ (posting engine)
- เอกสารที่ไม่ลงบัญชี (ใบเสนอราคา/ใบขอซื้อ/ใบสั่งซื้อ/ใบวางบิล) แค่เปลี่ยนเป็น approved ไม่สร้างสมุดรายวัน
- **ฝั่งขาย**: เดบิต ลูกหนี้ / เครดิต รายได้รายบรรทัด + เครดิต ภาษีขาย (ถ้าหัก ณ ที่จ่าย: เดบิตภาษีถูกหัก / เครดิตลูกหนี้)
- **ฝั่งซื้อ**: เดบิต ค่าใช้จ่าย/สินค้ารายบรรทัด + เดบิต ภาษีซื้อ / เครดิต เจ้าหนี้ (ถ้าหัก ณ ที่จ่าย: เดบิตเจ้าหนี้ / เครดิตภาษีหัก ณ ที่จ่ายค้างนำส่ง)
- เลขที่สมุดรายวัน `BOOK-YYMM-NNNN` (SALE/PURCHASE/ADJ) · ตรวจงวดเปิดก่อนลงทุกครั้ง · ลงซ้ำไม่ได้ (idempotent)

### เลขที่เอกสาร
ออกอัตโนมัติตอนบันทึกใหม่ ตั้งรูปแบบแยกทุกประเภทที่ `/settings/numbering` (prefix/ปี/เดือน/ลำดับ, รีเซ็ตรายเดือน/รายปี) · prefix seed: QU, BN, IV, TX, RE, CN, DN, DR, PR, PO, GR, BL, EX, PC, PD, DP

## 5. ผังบัญชี

ผังบัญชีแบบกรมพัฒนาธุรกิจการค้า (DBD) seed ให้ทุกบริษัท บัญชีหัว (is_header) เป็นยอดรวม ลงรายการไม่ได้ · บัญชีระบบผูกด้วย system_key (เช่น `ar`, `ap`, `vat_output`, `depreciation`)

| ช่วงรหัส | กลุ่ม | ตัวอย่างสำคัญ |
|---|---|---|
| 1xxx | สินทรัพย์ | 1110 เงินสด, 1120 ธนาคาร, 1130 ลูกหนี้, 1150 สินค้าคงเหลือ, 1160 ภาษีซื้อ |
| 12xx | สินทรัพย์ไม่หมุนเวียน | 1210 ที่ดิน, 1220 อาคาร/1221 ค่าเสื่อมสะสม, 1230 เครื่องจักร/1231, **1240 เครื่องใช้สำนักงาน/1241**, 1250 ยานพาหนะ/1251 |
| 2xxx | หนี้สิน | 2110 เจ้าหนี้, 2140 ภาษีขาย, 2150 ภาษีหัก ณ ที่จ่ายค้างนำส่ง, 2160 ภาษีมูลค่าเพิ่มค้างจ่าย |
| 3xxx | ส่วนของผู้ถือหุ้น | 3120 ทุนชำระแล้ว, 3220 กำไรสะสม, 3230 กำไรสุทธิงวดนี้ |
| 4xxx | รายได้ | 4110 รายได้ขาย, 4120 รายได้บริการ |
| 5xxx | ต้นทุนขาย | 5110 ต้นทุนขาย, 5130 ซื้อ |
| 6xxx | ค่าใช้จ่ายขายและบริหาร | 6110 เงินเดือน, 6120 ค่าเช่า, 6140 โฆษณา, **6170 ค่าเสื่อมราคาและค่าตัดจำหน่าย** |
| 7110/8110 | ต้นทุนทางการเงิน / ภาษีเงินได้ | ดอกเบี้ยจ่าย / ภาษีเงินได้นิติบุคคล |

> **กติกาค่าเสื่อมสะสม = รหัสบัญชีสินทรัพย์ + 1** (1220→1221, 1240→1241 ...) ใช้ตอนรับค่าเสื่อมจาก ONE Asset

## 6. รายงานและภาษี

รายงานทั้งหมดอ่านจากสมุดรายวันจริง (ไม่มีตัวเลขกรอกเอง): งบทดลอง, งบกำไรขาดทุน, งบแสดงฐานะการเงิน (กำไรสะสมคำนวณจาก P/L), งบกระแสเงินสด, อายุลูกหนี้/เจ้าหนี้, KPI, งบเทียบสองงวด, ดูลึกรายบัญชี (drill-down) · ภาษี: รายงานภาษีขาย/ซื้อ, ภ.พ.30, หัก ณ ที่จ่าย + พิมพ์หนังสือรับรอง, ภาษีซื้อรอใช้สิทธิ์, e-Tax

## 7. ทรัพย์สินถาวรและการเชื่อม ONE Asset

ONEBOOK เก็บตาราง `fixed_assets` และฟังก์ชันภายใน (เช่น `capitalize_asset` แปลงบิลที่ลงบัญชีแล้วเป็นทรัพย์สิน, `run_depreciation` คิดค่าเสื่อมภายใน) แต่ **การบริหารทรัพย์สินจริงย้ายไปทำที่ ONE Asset** ส่วน ONEBOOK รับบทบาทสมุดบัญชีหลัก เชื่อมผ่าน 2 endpoint:

### A. ส่งรายการทรัพย์สินให้ ONE Asset — `GET /api/integrations/asset-candidates`
คืนบรรทัดของเอกสาร **bill/expense ที่ผ่านรายการแล้ว** ซึ่งลงบัญชีสินทรัพย์รหัส **12xx** (ไม่ใช่บัญชีหัว) ให้ ONE Asset ดึงไปขึ้นทะเบียน · ยืนยันตัวตนด้วย header `x-asset-key`

### B. รับค่าเสื่อมจาก ONE Asset — `POST /api/integrations/depreciation-journal`
รับ `{company_id, period_end, lines:[{amount, asset_account_code, description}]}` แล้วเรียก `post_external_depreciation`:
- ลงสมุดรายวันเล่ม ADJ **เดบิต 6170 (ค่าเสื่อม) / เครดิต รหัสสินทรัพย์+1 (ค่าเสื่อมสะสม)** รายบรรทัด
- 1 ชุดต่อบริษัทต่องวด · **กันลงซ้ำ** (ถ้ามีงวดนั้นแล้วคืนเล่มเดิม) · ตรวจงวดเปิดก่อนลง

> ทั้งสอง endpoint ยืนยันด้วย `x-asset-key` = env `ASSET_SYNC_KEY` (ต้องตั้งให้ตรงกับฝั่ง ONE Asset) · ฟังก์ชัน `post_external_depreciation` อยู่ใน migration **0077** — ต้อง deploy migration นี้ขึ้นฐานข้อมูลจริงด้วย ไม่งั้นการส่งค่าเสื่อมจะล้มเหลว (500 ไม่พบฟังก์ชัน)

ดูสถาปัตยกรรมเต็มที่ `shd-platform/docs/INTEGRATION.md`

## 8. การปิดงวดและความปลอดภัย

- **ปิดงวด (Freeze)** ที่ `/settings/period-lock` — ห้ามบันทึก/แก้เอกสารวันที่ ≤ วันที่ปิด (ยกเว้นผู้มีสิทธิ์ปลดล็อก) มีแถบเตือนบนหัวเมื่องวดถูกปิด
- **ตรวจก่อนปิดงบ** (`/accounting/close-check`) และ **ปิดบัญชีสิ้นปี** (`/accounting/year-end`) ล้างรายได้/ค่าใช้จ่ายเข้ากำไรสะสม
- ความปลอดภัย: RLS ตามบริษัท, สิทธิ์ `app.has_perm`, มาส์กคอลัมน์/กรองแถว, ประวัติการใช้งาน (audit) · SSO OIDC (PKCE) พร้อม logout ที่ระบบกลาง
